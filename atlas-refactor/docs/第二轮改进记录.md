# 第二轮：教学关联与真实像素特征

范围：继续完善现有五个地质勘察案例，不扩展其他环节。案例包版本更新为 1.1.0。

## 本轮变化

1. **图像特征计算链。**构造线和露头裂缝先渲染灰度图，再通过纯函数从观测像素计算暗度、局部暗脊响应和结构张量方向一致性。提取函数不接受标签或潜在几何，独立真值仅用于训练标签和评估。
2. **有效的参数控制。**图件案例移除没有实际作用的“决策阈值”，改为最小连通区域面积。化探案例增加独立的异常距离阈值，聚类数与阈值各自承担不同作用。
3. **专业解释。**五个案例各自定义术语、概念控件含义及逐步图解说明，保存在其唯一 `.case.ts` 维护入口。避免把所有背景控件都称为“剖面切位置”。
4. **流程与中间产物。**训练采样步骤展示真实参考图与采样位置；标准化步骤使用实际标准化通道；图件分类与面积合并分开展示；化探中心迭代可以按真实保存的历史逐步检查。
5. **联动检查。**原图、预测图和误差图共享选点标记；方向键移动选点。kNN 距离图跟随选点更新，散点和异常样点排序支持点击定位，散点支持键盘 Enter/Space。
6. **修复方向高亮口径。**裂缝方向图和高亮均基于细化骨架，避免一边统计骨架、一边高亮原掩膜。
7. **可测计算模块。**实验计算从 DOM 渲染中分离到 `experiment.ts`，可独立验证参数、预测、标准化和数据划分。

## 复现本轮改进

- 遥感案例：专业背景点击“波段”；流程点击“选择标注”；演示点击图像后按方向键，检查距离图是否对应当前像元。
- 化探案例：流程点击“中心迭代”，调整更新步；演示分别调整 K 和异常阈值，点击高分样点检查其位置。
- 图件案例：先增加观测扰动，再比较最小面积 1 与 60 的结果。注意规则可能错误合并真实小区域，不保证指标单调提升。
- 裂缝与构造线：观察灰度原图、局部暗脊特征、分类分数、后处理及错误，而不是把预先生成的目标距离当成模型输入。

## 仍然保留的边界

输入图像仍为程序合成，未接入真实遥感或现场照片，也没有深度模型。裂缝仍是二维骨架统计；图件仍是像素坐标区域。Worker、完整管理迁移、跨源历史迁移及公共脚本托管防护仍在后续完善范围。不得把本轮解释为已完成真实现场系统。
