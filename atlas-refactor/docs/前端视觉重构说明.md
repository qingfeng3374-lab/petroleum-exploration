# 前端视觉与交互重构 · v1.2.0

本轮依据“全面重构前端、强化交互与动画”的要求，重新设计主站与五个新案例的视觉界面。界面以地下勘探为主题，采用岩层深绿、铜金、矿物青和岩性分色；首页的信息组织、三维场景和案例呈现均已重做。

## 可以直接体验的变化

| 区域 | 新的呈现与操作 |
| --- | --- |
| 首页首屏 | 起伏地形、四层剖面、层面纹理、井位指示、粒子与扫掠平面构成实时 Three.js 场景。 |
| 三维地层 | 拖动或方向键旋转；展开 / 合拢地层；开关扫描、自转；重置视角；点选模型或左侧层位按钮查看说明。 |
| 作业链 | 13 个环节组成连续路径。选择节点后，环节介绍与场景入口同步切换。窄屏可横向滚动节点。 |
| 智能方法 | 五类方法围绕地质数据形成关系图；选中节点后展示方法描述、数据类型及对应场景入口。 |
| 案例展台 | 五个案例使用不同的概念图；选择左侧实验，右侧切换预览、说明和入口。 |
| 案例库 | 每个案例有独立视觉预览，保留打开、下载与移除操作。 |
| 场景与方法页 | 统一更新标题、场景条目、方法标签、筛选器、页签、相关场景和空状态。 |
| 实验内页 | 控制面板、地图窗口、指标、流程、图表、术语说明使用统一的实验界面。 |
| 流程演示 | “自动演示流程”依次展示真实中间产物；可随时暂停、手动选择步骤。离开流程页或后台隐藏时停止。 |
| 滑动对照 | 在案例演示中展开“滑动对照”，直接拖动图像或使用滑块，比较同位置的观测与模型候选。 |
| 添加案例 | 新的导入窗口与投放区；打开后聚焦窗口，Tab 在窗口内循环，Esc 关闭并恢复焦点。 |

首页预览图属于方法概念示意；进入案例后，实验图和指标仍由既有算法实际计算。没有增加新行业阶段或虚构真实数据成果。

## 动效与适配

- 三维模型按需加载，限制像素密度，页面隐藏或离开可见区域时停止绘制，退出首页释放 WebGL 资源。
- 首页包含地震信号流动、连线运动、轨道旋转、概念图扫描、区块入场与选中态反馈。
- 顶栏可暂停装饰动效，偏好保存在当前浏览器；五个新案例同步接收暂停状态。
- 遵循系统“减少动态效果”设置；保留按钮、方向键和主动流程播放等必要操作。
- WebGL 不可用时显示二维概念剖面。
- 分别检查 1440px 桌面、768px 平板、390px 手机；三维相机按视口比例适配。
- 所有图形、动画与字体回退均可本地运行，无在线图片或字体请求。

## 验收与复现

```powershell
npm run check
npm test
npm run build
# 在另一终端启动 npm run dev，并按实际端口设置：
$env:ATLAS_TEST_URL='http://127.0.0.1:5173/'
node tests/visual-redesign.mjs
node tests/browser.mjs
node tests/learning-upgrade.mjs
node tests/compatibility.mjs
node tests/legacy-modes.mjs
```

新增视觉回归覆盖：三维展开、键盘旋转、层位选中、环节 / 方法 / 案例切换、流程播放、滑动对照、动效同步、导入窗口焦点、减少动效和移动端溢出。浏览器脚本使用本机 Chrome。

结果记录在 `docs/*-results.json`；新版截图以 `docs/screenshots/redesign-` 开头。`release/single`、`release/legacy`、`release/archives` 中五个案例均已更新到 v1.2.0。

浏览器中之前手动导入的旧案例包保留其自身版本。若想替换为新版，可移除该导入版本并导入新的单文件包；协作者的旧包接口继续兼容。原站快照仍保留在 `public/legacy`，用于兼容验证和旧管理工作台。
