## 相对完整方案的简化与限制

这是一版可以审核与继续迭代的教学系统，以下项目没有按最完整设想实现：

1. **输入仍为合成教学数据。**新增案例也使用合成曲线、特征、时序与文本，不代表真实区块验证。构造线和裂缝已从观测灰度像素实际提取暗度、暗脊和方向一致性，提取函数不读取真值。尚未接入真实影像、传感器标定或深度模型；不能称为真实遥感/露头识别系统。
2. **场景专属解释仍可加深。**已有不同背景示意和每步中间图，但部分公共步骤框架与旧站降级图解仍复用同一表达结构；地质专家审核后可完善术语、成因和更接近现场的数据。
3. **裂缝统计为局部骨架方向。**方向图不代表独立裂缝条数；容差指标是像元邻域匹配，不是完整的一对一线段匹配。尚未实现产状反演、物理尺度密度或严格轴向分布误差。
4. **图件输出为区域标签及边界线段。**没有闭合多边形拓扑、地理配准或 OCR；边界采用图像像素坐标。
5. **计算在主线程、延迟防抖执行。**默认规模实测较小，尚未启用 Worker。连续参数请求会取消尚未开始的计算，执行中的同步计算不可中断。
6. **管理仅作用于当前浏览器。**原生管理已覆盖技术、场景、案例元信息和账号设置，但没有服务端身份认证、多人同步或云备份；本地登录不能视为远程权限边界。
7. **历史迁移要求同源。**现已覆盖旧 v1/v2 案例、隐藏名单及方法/场景覆盖层，恢复会先整体校验并在失败时回滚。跨端口、跨电脑及 file:// 的独立存储不会自动互通，需要导出备份；复杂第三方存储格式不保证可迁移。
8. **导入契约采用显式运行时校验。**附有 JSON Schema 文档，但未集成通用 Schema 引擎。路径与引用继承旧宿主行为，复杂同名资源或现代 ESM 包应先预打包再导入。
9. **消息以 iframe source 为边界。**已核对消息来源与类型，未实现方案中的独立会话 token 协议。导入包仅用于本地可信协作者，不应直接当作公共不可信脚本托管平台。
10. **三维图在首页与作业链按需加载。**作业全景已有完整地层与设备模型；案例背景仍使用可调二维/轴测概念图，尚未把 WebGL 模型嵌入每个背景页。Three.js 分包约 747 kB，进入首页后异步加载；构建对该包给出体积提示。WebGL 不可用时呈现二维剖面。
11. **旧外部脚本保留为静态资源。**Vite 提示兼容宿主脚本不参与 ESM 打包；它已随 dist 复制并通过生产环境导入测试。
12. **测试覆盖为本机 Chrome。**尚未在 Safari、Firefox、真实低端手机做全面验证；存储配额耗尽、复杂路径冲突和长时间内存增长没有全面压力测试。

这些限制保留在交付文档中，不通过预制准确率、假进度或错误方法标签掩盖。本轮已按用户确认扩展到13环节。后续应优先用真实且可公开的数据验证代表性案例，再决定是否覆盖剩余44个场景。

## 建议审核路径

1. 启动网站，确认首页两条检索路径及总数。
2. 地质勘察 → g1 → 遥感岩性识别，依次看背景、选择流程步骤、进入演示。
3. 修改 k 与观测扰动，点击像元查看投票，选择强干扰与少样本预设，再重置。
4. 在 g1 上方切换构造线案例，比较不同输出与错误。
5. 化探案例观察 K-means 迭代与样点排序；图件案例看边界；裂缝案例点击方向图查看高亮。
6. 下载任一 HTML，独立打开；移除内置版本后通过“添加案例”上传并刷新。
7. 将 `release/legacy/` 对应目录上传原站，检查三部分及示范内部导航。

五个地质案例默认测试种子为 `20261023`，十二个新增章节案例为 `20261103`；参考种子为 `77123`，时序预测按时间划分。默认扰动为 `0.25`，kNN 的 k 为 5，K-means 的 K 为 3。固井分类阈值为 0.5，初至分数阈值为 0.6。强干扰设为 1.1；各案例的第二预设模拟参考不足、参考污染、术语或工况变化等实际限制。重新生成测试数据会改变测试种子。
