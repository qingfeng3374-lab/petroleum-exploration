# v1.3.0：主题、双语、阅读排版与手动添加

## 使用入口

- 顶部“亮色主题 / 暗色主题”可随时切换外观；“EN / 中文”切换语言。选择保存在当前浏览器，刷新后继续使用。
- “添加案例”窗口包含“文件导入”和“手动添加”两个入口。原有文件夹、多文件、单 HTML 和拖放导入继续可用。
- 五个可下载单文件实验也带有独立主题与语言按钮。嵌入主站后由主站统一控制。

## 外观与阅读

暗色保留森林绿和琥珀色。新增亮色采用暖白背景、朱橙主按钮、翡翠绿选中态及矿物紫图表，地层和案例预览提高色彩饱和度。

主站正文主要使用 15–16 px，导航和主要操作使用 13–15 px，辅助说明主要使用 11–13 px。实验正文使用 14–15 px，控制标签、指标和图例同步放大。坐标、图形内的刻度等装饰或密集标注单独控制字号。

重新调整导航换行、卡片内边距、正文行高、实验参数区、表单布局和移动端断点。吸顶页签根据实际导航高度定位，兼顾中文和较长的英文文本。三维模型在暂停动效后仍保留画面。

## 双语范围与状态

中英文覆盖主站导航、13 个环节、61 个场景、方法说明、导入窗口、五个地质实验的背景、术语、流程、参数、指标及动态反馈。历史测井示范增加英文说明与界面适配，英文说明根据原材料编写。

切换语言不会翻译或改写用户导入的案例正文；作者内容按原文显示。原站兼容管理工作台保留原版界面。自行编写的演示 HTML 若希望响应主题和语言，需要实现下述消息约定。

五个实验的主题与语言在原 DOM 上更新，不重新初始化算法。已调整的参数、种子、选中像元、对照分隔位置以及计算结果保留；语言切换前后的结果 JSON 经比较一致。流程播放的既有逻辑继续生效。

主站发送：

```js
{ atlas: true, type: 'set-preferences', theme: 'light', language: 'en' }
```

演示页面接收时应检查 `event.source === parent`，并验证 `theme`、`language` 取值。`set-view`、`set-motion`、`ready` 和 `resize` 的既有协议继续保留。

## 手动添加和原导入表单

手动添加恢复并扩展了原站字段：

| 内容 | 说明 |
|---|---|
| 案例名称、ID | 名称必填；ID 使用小写字母、数字、连字符，并校验重复 |
| 所属场景 | 按作业环节分组选择，沿用原场景 ID |
| AI 技术 | 支持多选，未勾选时继承场景的方法 |
| 版本、更新日期 | 可手动修改 |
| 背景简介、内容 | 背景内容必填，支持纯文本和经过清理的 HTML |
| 流程步骤 | 可增删；每步包含名称、操作、预期结果和注意事项 |
| 演示 HTML | 可选，脚本仅放在演示资源中，通过 iframe 沙箱执行 |

先导入文件时，同样显示名称、ID、场景、方法、版本和日期字段，可以调整后再添加。背景预览、演示试跑、校验反馈及 ZIP 导出均位于窗口中。

保存使用现有 IndexedDB 存储，刷新后恢复。ZIP 包包含 `case.json` 与演示资源；再次导入时先解压。相同 ID 仍按原规则提示重复，可修改 ID 或先移除旧版本。资源总量限制维持 6 MiB。
