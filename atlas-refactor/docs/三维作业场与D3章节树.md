# 三维作业场与 D3 章节树

更新：2026-11-03。主站 v1.6.0；现有五个地质案例的算法与导入协议保持原样。

## 本轮改动

首页“穿行于地上与地下”及作业链页面的二维全景，已替换为左侧 Three.js 三维作业场、右侧 D3 可展开章节树。原来的“方法关联”和统计矩阵仍可使用。

三维场景不是将原来的平面图倾斜显示，而是由可旋转的地层网格、井筒管线、塔架、物探车、录井房、抽油机、集输管道和炼化设备组成。标签从三维坐标实时投影到页面，并提供编号按钮。

章节树采用 `d3-hierarchy` 组织真实场景数据，使用 `d3-shape` 绘制连接曲线。结构为：

- 发现地下：地质勘察、物探。
- 建井与开发：钻井、录井、测井、固井、完井、射孔、采油。
- 维护、增采与地面工程：修井、增采、运输、加工。

三章共覆盖 13 个环节、61 个场景。章节名称、场景名称和数量来自当前网站数据；本地增加、删除或编辑场景后会同步更新，不另维护一份目录。

## 使用方式

| 操作 | 结果 |
|---|---|
| 拖动三维画布 | 围绕作业场旋转 |
| 滚轮、缩放按钮 | 放大、缩小模型 |
| 全景 / 地表设施 / 地下剖面 | 切换观察位置 |
| 分层展开 | 分离地层，观察井筒与储层的空间关系 |
| 点击模型上的编号 | 选择环节，右侧自动展开对应章节，并显示业务解释 |
| 点击章节树中的环节 | 高亮对应的三维编号，同时展开其场景 |
| 点击场景 | 进入原有场景详情与案例页面 |
| 搜索章节或场景 | 保留匹配内容及其祖先节点；搜索章节名可查看该章所有场景 |
| 全部展开 / 收起 | 查看全部目录或回到三章概览 |
| 方向键、加减号、Home | 三维画布聚焦时旋转、缩放、重置 |
| 章节树方向键 | 上下移动焦点，左右展开、收起或进入父子节点 |
| 顶部动效开关 | 暂停抽油机及其他装饰动效；手动操作仍可用 |

桌面采用左右并列布局，窄屏改为上方模型、下方章节。手机模型保留编号以避免文字遮住设备，具体名称和解释可在选中说明与章节树查看。长标签提供完整标题提示。

## 地质和工程表达依据

模型使用“上覆岩层—盖层—储层—烃源岩—深部岩层”的简化剖面。盖层位于储层上方，砂岩储层前缘以点状孔隙示意流体分布；井筒、射孔与注入线用于说明作业和储层的联系。首页原有地层模型的盖层、储层顺序也已同步校正。

参考以下一手资料，内容采用概念性转述，没有复制外部模型或图片：

- [SLB：Petroleum system](https://glossary.slb.com/terms/p/petroleum_system)：石油系统涉及烃源岩、运移、储层、圈闭和盖层等要素，并受到形成时序影响。
- [SLB：Reservoir](https://glossary.slb.com/terms/r/reservoir)：储层是具备储存和传输流体能力的岩体，不能理解成地下空腔或“油湖”。
- [SLB：Trap](https://glossary.slb.com/terms/t/trap)：圈闭依赖合适的岩层配置和封闭条件。
- [SLB：Cementing](https://glossary.slb.com/terms/c/cementing)：固井可用于封隔套管环空等工程目的，模型中的环带不代表储层。
- [Three.js：OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)：旋转和缩放交互。
- [D3：Hierarchy](https://d3js.org/d3-hierarchy/hierarchy)：章节的层级结构与遍历。

模型保留概念边界：不是实际区块、真实井深或生产仿真；同一井筒不同生命周期的作业阶段并列显示，不能理解为同时施工。地层展开的间隙也是观察手段，不是岩层之间真实存在的空隙。抽油机、塔器仅代表对应环节的一类设备。

## 实现与运行

- `src/components/AtlasExplorer.svelte`：三维章节视图与原方法关联视图切换。
- `src/components/FieldScene.svelte`：三维控件、投影标签、环节说明和参考入口。
- `src/field/scene.ts`：地层、设备、井筒建模，OrbitControls、点选、渲染及资源释放。
- `src/components/ChapterTree.svelte`：展开状态、搜索、键盘访问和双向联动。
- `src/field/chapters.ts`：D3 层级数据与连线布局。
- `src/field/knowledge.ts`：概念位置、章节分组、配色和环节知识说明。
- `src/field.css`、`src/i18n/field.en.json`：响应式样式与英文文本。

三维代码在模块接近视口时按需加载，离屏和后台标签页停止绘制；尊重系统减少动效设置。退出视图时释放几何体、材质、控制器和 WebGL 上下文，反复切换不会一直累积实例。模型无需外部纹理或在线三维资源。

WebGL 创建失败时显示分层占位说明，章节树依然可以搜索、展开全部 61 个场景并跳转。亮暗主题、双语和已有案例功能继续保留。
