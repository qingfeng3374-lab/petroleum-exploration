# 操作入口与返回导航优化

本轮解决案例下载藏在页面底部、次要操作接近正文、页面缺少返回入口的问题。

## 已调整的入口

- 案例库将“下载案例”放到当前案例标题旁，与“进入完整实验”并列。下载采用绿色实色按钮、下载图标和 HTML 格式提示；移除原先底部重复的下载链接。
- 案例详情页增加“返回案例库”“下载案例”“运行演示”操作区，背景、流程和演示中均可找到案例下载入口。
- 五个自包含地质案例下载为 HTML；用户导入的案例提供 ZIP 下载，保留清单、演示文件和二进制资源。历史测井继续使用站内演示。
- 其他操作采用统一图标、文字标签、边框或背景色；放大背景阅读、清单模板下载、案例切换和移除按钮的点击区域。
- 首页进入实验室、探索区进入环节和协作入口更容易辨认，页尾新增“回到页首”。
- 完整实验内强化重置、失败预设和导出操作的层级；结果导出明确标记为 JSON，独立 HTML 文件同步更新。

## 返回行为

所有非首页页面提供“返回上一页”按钮和当前位置导航。返回使用站内访问历史，背景、流程和演示页签视为同一页面，因此不会逐个页签退回。

从案例库进入详情后，返回会保留之前选择的案例。刷新后仍能识别已记录的站内历史，浏览器前进与返回也可继续使用。直接打开详情链接时，按钮显示“返回案例库”；直接进入其他页面时使用对应的作业链或首页入口。直接进入页面后的返回使用替换导航，避免在详情和案例库之间反复跳转。

## 排版与验证

主要操作字号为 16–17 px，按钮高度至少 48 px。手机上将案例操作纵向排列；明暗主题、中英文模式分别适配。

实现位置：

- `src/actions.css`、`ActionIcon.svelte`：按钮样式与图标。
- `PageNavigation.svelte`、`services/navigation.ts`：当前位置和返回历史。
- `CaseDownload.svelte`、`services/export-case.ts`：HTML 下载及导入案例 ZIP 导出。
- `CaseLibrary.svelte`、`App.svelte`：操作位置和案例选择恢复。
- `case-sdk/presentation.css`：完整实验操作样式。

验证结果：

- `npm run check`：0 错误、0 警告。
- `npm test`：20 项通过。
- `npm run build`：成功更新主站和可下载案例。
- `tests/actions.mjs`：实际 HTML 下载、ZIP 清单与二进制文件保留、跨页返回、跳过页签、刷新恢复、案例选择保留、前进后重新访问、直接链接后返回均通过。两种主题、两种语言在 390 / 768 / 1440 px 下检查按钮点击区域和整页溢出。
- `tests/preferences.mjs`：主题、语言、完整实验状态、手动添加和 ZIP 重新导入回归通过。
- `tests/preparation.mjs`：准备清单、语言切换和历史测井回归通过。

浏览器验证使用本机 Chrome。结果见 `actions-results.json`；截图为 `screenshots/actions-*.png`。
