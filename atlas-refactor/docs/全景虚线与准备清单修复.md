# 全景虚线与准备清单修复

## 已确认的问题

1. 首页和作业链全景中，钻井下方的 L 形虚线来自单独绘制的装饰路径。它没有图例、没有关联数据，也没有交互，却容易被理解成作业链分支。现已移除；连接十三个环节的连续作业路径保留。
2. 历史测井案例的“你需要准备什么”使用旧版 `K.checklist` 生成的 HTML。主站原先只渲染了这段 HTML，没有接入旧版样式或 `bindChecklist` 逻辑，导致方框不可见、文字挤在一起、点击无效、计数停留在 `0 / 5`。英文版本原先也仅为普通列表。
3. 该模块的两条公开数据集链接都错误指向站内 `#/method/cv`，不能打开对应的数据来源。

## 修复方式

- 删除 `AtlasExplorer.svelte` 中额外的井轨迹装饰线。
- 内置测井案例的背景页改用 `WelllogBackground.svelte`；准备模块由 `WelllogPreparation.svelte` 渲染原生复选框、已确认项数和进度条。
- 清单以“数据与参考规格 / 用途与标注要求”分列，手机按条目纵向排列；正文、名称和说明使用 16–18 px 字号。
- 支持整行点击、空格键勾选和清空；主题、语言切换保留状态，离开背景页或刷新后重置。进度表示用户自行确认，不做自动质量判断。
- 明确原案例中的井数、采样间隔和点数是参考设定，不是通用项目门槛。
- 公开数据入口改为经核对的 [FORCE 2020 项目仓库](https://github.com/bolgebrygg/Force-2020-Machine-Learning-competition) 和 [KGS LAS 数据检索](https://www.kgs.ku.edu/Magellan/Logs/)。链接在新标签页打开，避免离开背景页时丢失勾选状态。
- 背景章节补充分隔、参考链接间距及滚动偏移，防止吸顶页签遮挡小节标题。

本次针对主站中的内置测井背景页；旧兼容工作台及用户自行导入的案例原文不作覆盖。五个地质实验的计算方法未改变。

## 验证

`tests/preparation.mjs` 覆盖鼠标与键盘勾选、计数和进度、全选与清空、中英文与主题切换保留、离开与刷新重置、真实数据集链接、历史测井演示，以及两种语言在 390 / 768 / 1440 px 的布局和字号。结果见 `preparation-results.json`，截图见 `screenshots/fix-*.png`。

`npm run check` 为 0 错误、0 警告；原有 20 项测试通过；生产构建已更新。
