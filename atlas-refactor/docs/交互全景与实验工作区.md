# v1.4.0：交互全景、实验工作区与导航重构

本轮针对案例列表重复、首页布局模板化、字号偏小和导航拥挤进行修改。保留 13 个环节、61 个场景、五个地质实验及历史测井案例，沿用原来的场景 ID、导入协议和计算逻辑。

## 从重复卡片改为实验工作区

案例库改为“案例索引 + 当前实验”，不再重复堆叠六组相似预览图、介绍和操作按钮。桌面索引放在左侧，窄屏可横向滚动选择；当前案例的介绍、计算画面、参数和入口集中在工作区。

五种预览调用现有 `runExperiment`，不是预制结果图：

| 案例 | 工作区中的画面与操作 |
|---|---|
| 化探异常识别 | D3 异常分数等值线与样点，调整背景中心数和噪声 |
| 地质图件要素提取 | 原图与分类区域对照，实际区域边界，调整最小区域面积 |
| 构造线候选提取 | 灰度观测与模型候选叠加，调整分界和阈值 |
| 遥感岩性识别 | 三波段观测与 kNN 分类对照，调整邻居数和分界 |
| 露头裂缝统计 | 实际骨架与方向玫瑰图，观察阈值和噪声的影响 |

画面支持指针与方向键检查像元，并显示本次合成测试的 Macro-F1。历史测井直接加载原有可运行演示；用户导入的案例展示自己的内容与入口。原有案例没有因图片相似而被删除。

预览使用固定种子 `18127`、默认噪声 `0.35`，与完整实验共用计算函数，但参数状态独立。进入完整实验后仍可使用背景、流程、实验三个页签、失败预设、指标和导出等原功能。所有预览数据均为合成教学数据；玫瑰图展示局部骨架方向，不表示独立裂缝条数。

## 首页与作业链

撤掉原来的水平时间线加说明框、五节点圆形方法菜单和重复案例展台，改为一个可切换的探索区：

- **作业全景**：D3 等值线构成概念地形，十三个环节使用不同的现场 SVG 图形，沿连续路径连接。选择环节后显示其业务说明和场景入口。
- **方法关联**：五类方法连接十三个作业环节，连线粗细来自实际场景数量。选择方法、环节后查看交集，也可进入该方法的全部场景。
- **三维地层**：保留 Three.js 的旋转、展开、扫描、层位选择和键盘操作，改善亮色主题下的地面网格对比度。
- **动效**：路径流动、扫描线、三维交互均服从全站动效开关和系统减少动效设置。三维图离屏停止绘制。

概念地图明确标注非真实地理位置。小屏使用地图内横向滚动，保持节点和文字的大小，不把整张图缩到难以阅读。场景列表也改成留白清楚的连续行，减少重复边框。

## 导航与字号

桌面导航分为品牌、页面入口、偏好工具和添加案例按钮。主题、语言、动效按钮有可访问名称与悬停说明；当前页面通过下划线和 `aria-current` 标示。窄屏切换为折叠菜单，支持 Escape、点击外部和跳转后关闭，添加案例始终可见。

主站正文主要为 17–18 px，导航和主要操作为 16–17 px，辅助信息主要为 14–15 px；完整实验正文与参数标签主要为 16 px。独立单文件案例和历史测井同步放大。密集图表内的坐标刻度属于单独处理的例外，作者导入内容和旧兼容工作台保留自身排版。

明暗主题、中英文模式、文件导入、手动添加、IndexedDB 保存、ZIP 导出与重导入继续可用。切换主题或语言不会重置五个完整实验的参数和计算结果。
